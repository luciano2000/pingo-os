# Pedido de aprovação no RetroAchievements

O texto para enviar à equipe do RetroAchievements (em inglês, texto puro para colar no formulário do site) está em [`retroachievements-pedido.txt`](retroachievements-pedido.txt). A primeira linha é o assunto; o resto é a mensagem.

Antes de mandar, confira no site deles (docs.retroachievements.org) o canal atual para pedidos de integração de emuladores.

# Pingo OS v0.2.0-beta (RG35XX-H)

Segunda versão de testes do Pingo OS by Retrogamer Brasil, para o **Anbernic RG35XX-H**.

> Beta: pode ter erros. Conte o que achou no [Discord do Retrogamer Brasil](https://discord.gg/DqBtrEWJak) ou nas [issues](https://github.com/luciano2000/pingo-os/issues).

## Novidades

- **RetroAchievements**: MENU no Início → RetroAchievements → Entrar (usuário e senha no teclado na tela; no cartão fica só um token, nunca a senha).
  - Ao abrir um jogo reconhecido: "X de Y conquistas".
  - Notificação de conquista com a imagem dela, deslizando de cima.
  - Menu do jogo → **Conquistas**: lista em ordem de pontos, com as imagens (coloridas nas conquistadas, em preto e branco nas bloqueadas) e a descrição numa caixa embaixo.
  - Modo hardcore: sem carregar save states e com as opções de core proibidas pelo RetroAchievements bloqueadas. *O Pingo OS ainda está pedindo aprovação ao RetroAchievements para o hardcore; até lá, use o modo normal (softcore), que já vale.*
  - Ainda não reconhece jogos em `.chd` (PlayStation, Sega CD, PC Engine CD).
- **Idiomas**: MENU no Início → Idioma. Português e **inglês**; a comunidade pode traduzir para outros ([como traduzir](https://github.com/luciano2000/pingo-os/blob/main/docs/traducao.md)).
- **Desligar** no MENU do Início (último item, com confirmação).
- A lista de jogos **lembra a linha** em que você estava ao sair com B e voltar.
- Segurança: o SSH (para desenvolvedores) só funciona pelo cabo USB, nunca pelo Wi-Fi.

## Atualizar a partir da v0.1.0-beta

Grave a imagem nova no mesmo cartão do slot 1, por cima. A partição `ROMS` (jogos, saves, configurações, Wi-Fi) é mantida.

## Instalação nova

1. Baixe o `pingo-os-rg35xxh.img.xz` abaixo.
2. Grave no cartão do slot 1 (TF1) com o balenaEtcher ou o Raspberry Pi Imager (aceitam o `.xz` direto). **Tudo no cartão é apagado.**
3. Ligue o aparelho: no primeiro boot, o Pingo pergunta se pode criar a partição de jogos (`ROMS`).
4. No PC, copie os jogos para `Roms/<CONSOLE>/` e as BIOS para `Bios/` ([lista de BIOS](https://github.com/luciano2000/pingo-os/blob/main/docs/bios.md)).
5. Wi-Fi: MENU no Início → Wi-Fi.

## Para quem desenvolve

Com o cabo USB no PC: `ssh root@192.168.7.2` (senha `pingo`). Conferir o download: `sha256sum -c pingo-os-rg35xxh.img.xz.sha256`.
